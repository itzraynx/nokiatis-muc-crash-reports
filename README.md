# Nokiatis MUC — Crash Reports

This repository collects crash reports from the **Nokiatis MUC** Android app
(Team Nokiatis). Each report is filed as a GitHub Issue by the in-app crash
reporter (Settings → Diagnostics → Crash reports → Upload).

Every report contains only technical diagnostics:

- app version / version code, Android version, device screen size
- the error message and JavaScript stack trace
- timestamp and whether the error was fatal

No personal data, no listening history, and no account information is ever
included. Reports are captured on-device first and only leave the device
when the user taps **Upload** (or shares them manually).

Issues here are triaged by Team Nokiatis and fixed in app updates.
